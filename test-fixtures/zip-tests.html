Zip reading tests

This page runs the real TakeoutZip.readZip() out of ../zip.js against archives it builds in your browser while you watch. Nothing is uploaded, nothing is downloaded, and no sample photo library is committed to this repository, because a real Takeout export is personal data. Every archive on this page is made here, checked, and thrown away.

The thing being checked is that a file read out of a zip is byte for byte the same file as the one you would get by unpacking it by hand, whichever way the zip stored it, and that a zip which is damaged or incomplete says so rather than quietly returning less.
